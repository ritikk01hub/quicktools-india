QUICKTOOLS INDIA - PROFESSIONAL MULTI-PAGE VERSION

Files included:
- index.html: homepage and tool directory
- One HTML file for each individual tool
- style.css: shared professional design
- script.js: existing tool functions
- about.html, privacy.html, contact.html
- sitemap.xml: includes the homepage and individual pages
- robots.txt

HOW TO PUBLISH ON GITHUB PAGES
1. Download and extract this ZIP on your PC.
2. Open https://github.com/ritikk01hub/quicktools-india
3. Before replacing anything, keep a backup of your current files.
4. Use Add file > Upload files and upload all files/folders from this extracted folder into the repository root. If prompted, replace existing index.html and add the new files.
5. Commit the changes to the main branch.
6. Wait for GitHub Pages to publish, then open https://ritikk01hub.github.io/quicktools-india/ and test every tool.
7. In Google Search Console, submit sitemap.xml again after the new pages are live.

IMPORTANT
- Replace the placeholder contact instructions in contact.html with a public email before launch.
- Check every tool after deployment. QR code generation requires an external QR service.
- Do not claim guaranteed Google rankings or income.
